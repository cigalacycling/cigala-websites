# Sample athlete pages (made-up data, marked SAMPLE)

For demos and tests of the athlete hub on **staging** only: send them to a test athlete with `POST /wp-json/cc/v1/report` (see `../../PC-TOOLS-HANDOVER.md`), then publish them in the Reports board.

- `season.html`: `type: "season"` (shows inside "Your season").
- `review.html`: `type: "review"`.
- `race-plan.html`: `type: "race-plan"`, or `prediction` / `race-sim` for those cards.
- `assessment.pdf`: `type: "assessment"`, sent as `pdf_base64`.

Not real athletes. Never send them on live.
